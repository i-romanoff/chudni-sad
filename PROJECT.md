# Сайт «Чудный сад» — статус проекта

> Файл-памятка: что сделано, как устроено, что дальше. Читай перед продолжением работы.

## Проект

Сайт-витрина питомника саженцев «Чудный сад» (домен **chudni-sad.ru**, зарегистрирован на timeweb до 01.09.2028).
Владелец: Карлук, телефон +7 924 707-14-00. Целевая аудитория — женщины 55+, основной просмотр с телефона.

План монетизации: сейчас витрина с заказом через корзину (без онлайн-оплаты), позже — e-commerce (VPS + PostgreSQL + платёжка ЮKassa/CloudPayments).

## Стек и структура

Чистый HTML/CSS/JS без сборки и зависимостей. Фреймворков нет — сайт переедет на любой хостинг.

- `index.html` — одна страница: шапка, фраза-обещание, hero, каталог с вкладками, «Как купить», контакты, подвал, мобильная панель, модалки (товар + корзина).
- `css/style.css` — вся стилизация. Палитра в `:root`: фисташковый фон `--paper: #e7f0d9`, тёмная хвоя `--forest-deep`, розовый `--graffiti-pink: #b23248`, лайм `--lime`. Шрифты: Roboto везде (body 18px), Prata — только «Чудный сад» в шапке, Caveat — рукописные бирки.
- `data/catalog.js` — **единый источник данных**: `window.CATALOG` (categories, shop, products). Цены в КОПЕЙКАХ (int). Схема товара и полей описана в комментариях вверху файла.
- `js/app.js` — рендер каталога/вкладок, корзина (localStorage, ключ `chudniSadCart`), маска телефона, модалки, слайдер, полёт в корзину.
- `assets/img/` — фото товаров (сжаты до ~1100px, JPEG q82), логотип, фавикон.

**Локальный запуск:** `powershell -ExecutionPolicy Bypass -File ..\serve.ps1` → http://localhost:8765 (serve.ps1 лежит в корне workspace, Python/Node на машине не установлены).

## Важные флаги и настройки

- `js/app.js`, константа `DEMO_COPIES = 4` — каждый товар клонируется ×4 (48 карточек) для предпросмотра ассортимента. **Перед публикацией поставить 1.**
- `data/catalog.js` → `shop.maxOrderEndpoint` — пусто. Когда появится релей MAX-бота, кнопка «Отправить в MAX» заработает автоматически (логика уже написана: POST JSON {name, phone, items, total, text}).
- Бейджи товаров: `badges: [{type: "sale"|"promo"|"soon", label}]`. Наличие: `stockCount` (1 → «Остался 1 шт» розовым; N → «В наличии · N шт»; 0 → «Продано», кнопка disabled; null → просто «В наличии»).

## Что сделано (всё проверено вживую в браузере, мобильный 375px + десктоп 1280px)

1. Дизайн-система: фисташковый фон, высокая контрастность (аудитория 55+, солнце), Roboto, крупный кегль, большие кнопки (52–56px), focus-visible, prefers-reduced-motion, skip-link.
2. Шапка: логотип-ирис (56px, round) + название, корзина со счётчиком (иконка с бейджем). Верхней кнопки «Позвонить» нет (по просьбе).
3. Hero: фото «Граффити» с фирменной белой биркой питомника (латинское название + рукописная строка), кнопки «Каталог» (одна строка на мобильном) и «Контакты».
4. Фраза-обещание под шапкой на тёмной полосе: «Все растения **подходят под наш климат и зимостойки**: то, что **не приживается у нас**, — не продаём» (акцент лаймом, по best practices emil-design-eng — типографика вместо коробок).
5. Каталог: 12 позиций (3 реальных: гортензии Граффити/Мечта Лесково, спирея Файерлайт + 9 тестовых заглушек по 3 в категории). Вкладки категорий: Хвойные, Плодные, Многолетники, Цветы (+Все, счётчики).
6. Карточки: бейджи (sale розовый / promo лаймовый / soon белый пунктир), плашка наличия справа, бирка с латинским названием, кнопка «В корзину» → «В корзине N» (синхронизируется со всеми кнопками через refreshAllAddButtons).
7. Модалка товара: слайдер фото (свайп/драг/точки/миниатюры), характеристики, кнопка с количеством. Скролл внутри `modal__scroll` (радиусы целы), тонкие скроллбары.
8. Корзина: localStorage, +/−, удаление, итого; «Сформировать заказ» → форма (Имя + Телефон с фиксированным +7 и маской +7 (XXX) XXX-XX-XX, только цифры) → превью текста → «Скопировать текст заказа» (работает) + кнопка MAX (неактивна до появления maxOrderEndpoint).
9. Полёт фото в корзину при добавлении (анимация + pop корзины).
10. Контacts: Позвонить + канал MAX. **Telegram полностью удалён** (по решению владельца).
11. Мобильная нижняя панель: Каталог · Корзина · Позвонить.
12. Исследован Bot API MAX: deep-link по номеру невозможен; бот шлёт сообщения сам (POST platform-api2.max.ru/messages, text ≤ 4000 символов, токен в заголовке Authorization, chat_id через подписку/updates). Создание бота — через business.max.ru/self (профиль самозанятого/ИП/юрлица; партнёрская программа не обязательна).

## Долги/заглушки (не забыть)

- Тестовые фото `conifer-*.jpg`, `fruit-*.jpg`, `flower-*.jpg` — сгенерированные заглушки с пометкой «тестовое фото», заменить реальными. В описаниях тестовых товаров стоит пометка «ТЕСТОВОЕ ОПИСАНИЕ».
- `DEMO_COPIES = 4` → 1 перед публикацией.
- Не заполнены `stockCount` у большинства товаров.

## Как обновлять каталог (для владельца)

Всё в `data/catalog.js`: скопировать блок товара, поменять id/name/цены/фото. Фото — в `assets/img/`, категория — одна из CATEGORIES. При акции добавить `badges: [{type:"sale", label:"Скидка 10%"}]`, при «скоро в наличии» — `{type:"soon"}`.
